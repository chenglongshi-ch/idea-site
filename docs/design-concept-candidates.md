## 甲. 苗圃·「留灯的苗圃」（+登记号变体 = 主线程合流推荐）

- **立意**：想法是种下去的活物；站是夜里也亮着补光灯的苗圃——暗色主题的叙事根据、solo 持续照料的诚实、为晚归访客留灯。
- **贯穿面**：词表原生（seed/growing/shipped 本就是园艺词；**shipped=「出圃」**——概念直接产出数据模型一直缺的中文词，原生性实证）；网格=育苗盘/卡片=盆位/双主题=昼夜同棚/缺图回退=空盆位/檐口=玻璃罩（catch-light 1px 反光线+灯带渐变）；hover=灯照上来（本概念唯一重注微交互）。
- **色字方向**：底=泥炭暖黑（转暖，非现冷蓝黑）；accent=补光琥珀（只照「活物」——P2 原则：标题栏铺 accent 拒）；显示层宋体系+正文黑体+数据 mono；状态色按生长阶段词重生成。
- **裁决性原则**（原案精华，可独立复用）：P1 农事实感禁插画 / P2 accent=灯只照活物 / P3 苗床密度不做花坛 / P4 昼夜同棚 / P5 词先于图（UI 名词在语域叫不出名就不配得到视觉）。
- **词表宪法**：概念词只住命名/空态/hero/about，不住功能动词（按钮仍叫搜索/打开/订阅）——做作的第一道闸。
- **红队标签**：hover 现状漏看三项须补处置（并入 v2.1-A#1 即消）；↗ 自违落码前修；无试样路径→用取用协议补。
- **登记号变体**：编号以「入圃登记号」存在（植物园 accession 模式：随株终身、出圃不注销）——保住永久 ID 四吃价值，概念纯度略让位（P5 答得出：入圃登记是农事实件）。synthesis-rulings §3。
- **风险**：SimSun 大字号成色未验（实机裁，降级=黑体+字重对比）；暖黑+琥珀低端屏显脏（验收含低端 LCD）；想法 <5 时 hero 计数行单薄（对冲=空盆位语义/撤计数行）。

## 乙. 苗圃·纯概念版（甲减编号）

- 甲的原案（A1）：编号只做苗床排号风装饰位。概念纯度最高（P5 全权裁决），代价=编号的「永久 ID 喂 AI 定点查询」价值打折——排号在隐喻内是位置不是身份，出圃即失效。红队裁定此为「编号的装饰面」，护城河面吃不到。

## 丙. 标本馆·「夜巡馆」（A2 dark-first 修正案）

- **立意**：一座夜间开放的想法馆藏室——每条想法一件编号藏品，demo 是黄铜灯带展柜里仍在动的活体。
- **贯穿面**：编号 IDEA-000n 贯穿卡片/页头/RSS/llms.txt（编号在此隐喻最原生）；四件套=柜格（.block 原样）/demo-head=展柜灯带（黄铜下边线+纸色带）/状态=章戳（border+fg 盖章式，token 值不动）/changelog=藏品档案行线。
- **色字方向**：墨青近黑（现 #0b0e14 微去蓝调）+章戳朱 #d94f35+黄铜 #c9a227（仅灯带三处）；圆角收紧 6px+纸感 token；衬线 ≥1.6rem 门槛。
- **落地质量**（红队实证）：A2 稿行号级对账 9/9 命中——三案中落地映射最扎实；token 表可直接折进 Layout.astro。
- **红队标签**：黄铜防线全在 demo 区、首页（试样地）零出勤——试样时首页信号=编号+衬线 hero 盯紧；「tinted 近黑」未辩解；圆角收紧≠同圆角结构拆除（须做分化=v2.1-A#2）。
- **风险**：中文「标本」自带已死味，全站文案终身强调「活体」对冲（红队+稿自认双重确认的软肋）；收藏冷静 vs 可玩热情的张力——hero 定位语必须自带「还在动」级信号词；编号 <10 条时仪式大于内容。

## 用户反应实录（2026-09-27，出题层教训）

用户对「选概念」提问的反应：「什么意思呀？你改变了我的目的了？功能与ui设计不冲突吧，多agent分析，并且沉淀下」——**开放型设计任务被收敛成隐喻单选题=出题层过度规范化**（underspec-prior-collapse 的姊妹失效模式：不是欠规范坍缩，是把宽题窄化后采集）。教训：设计轮尾的拍板问题须先对齐任务原语义（「UI 深化」≠「选概念」），概念只是子路线之一。
