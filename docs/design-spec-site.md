## ② 交互流

- **三跳流不变**：首页 → 想法页 →（页内 demo 可玩 或 直链页可玩），spec §7 验收主链，零改动。
- **iframe 高度（spec §8 第一开放点的合规回答）**：**首版定高 600px 维持，不上 scrollHeight 自适应**。理由：①定高已两轮实机背书（E1 520 → f260a0a 实测裁切上调 600）；②自适应要求每份模型直出产物携带量高协议脚本，污染「模型直出单文件」通道定稿，且模型产出高度随交互动态变（倒计时/展开态），resize 侦听复杂度进错层；③残余风险（个别 demo 仍裁切）由直链逃生门兜住。移动端由 ④ `min(600px, 80vh)` 兜底，不算推翻定高（裁决 #5）。回退案=演化位 E3。【实机验收 V1：首个真实想法 demo 在 600px 下不裁切为过线判据】

## ⑤ 状态与空态系统

- **三态视觉语言——够用，裁定保留**：seed 灰 / growing 黄 / shipped 绿，GitHub open/draft badge 同构，solo dev 心智零学习成本；饱和度排序（灰最低、黄最高）恰编码运营优先级——「在验证 = 最需要被点开」，色感与站主张力一致。收编 token（T2）后**别再加图标/描边动画**：三态是元数据不是装饰位。
- **hasDemo 与 status 解耦**：`[slug].astro:17` 以 `status !== 'seed'` 推断 hasDemo——状态与存在性耦合，工作流 spec §5 步 3（status→growing）先于步 2（生成 demo）执行时会渲染 404 iframe。修法 = 文件存在性探测（⑦-1，**代码必改项，不待 first-real-idea**），视觉面只消费布尔。
- **空态两档制成文（文案表在 ③）**：**块级空态**（占版面的：无 demo、无评论）= 虚线框 placeholder，句式「现状 + 转化去向」；**行内空态**（一行的：无日志、零想法）= muted 一行，不配框——日志是列表不是区块，框住空列表是给虚无盖房；**静默空态**（无 tag）= 不渲染，无信息即无噪音（四类里唯一正确答案已到位的）。判定法则一句话：**空态占不占版面，跟它有货时占不占版面对齐**——demo/评论有货是大块，空就框住宣示「这里会长出来」；日志有货是行，空就一行；tag 有货是字，空就消失。

## ⑥ 形态定位 ⏸（整体可翻案）

**第一版站在 halfbakery 朴素线一侧偏内：卡片纵列保留；neal.fun 全家只取一物——「可玩」信号的如实呈现，不取插画与网格。**

理由三条：①**产能事实**——neal.fun 线的视觉承诺靠插画喂养，solo 开发者无此产能，学半套（网格无插画）比不学更穷相；②**护城河错位**——本站空位在「想法原文→可玩 demo→反响」验证链（precedent 增量补验），视觉花哨会把站读成 demo 画廊，恰是要警惕的做偏方向；③**朴素线有生命力实证**——halfbakery 25 年纯文字列表活着，证明这个内容品类对视觉依赖度本就低，朴素不是妥协是匹配。

第一版落点：文字优先（卡片 = 标题+一句话+状态+日期，现 index.astro 已是此形，**不动**）；demo 在列表层不露脸（不做缩略图/预览帧），「可玩」信号由 growing/shipped 状态色承载——进想法页才是玩，列表页只管让人选。演化位 E5/E6/E7，共同前提「内容量先到」。【实机验收 V8：首页整页过目——纵列形态 + 状态色承载「可玩」信号成立】

## v2.1-C token 生成法（Radix「阶=职责」+Open Props 刻度，R1 P1 推荐）

- **色**：概念/材料 → 色族 → 每阶一个职责。site 实用阶：1 馆底(--bg) / 3 组件面(--surface) / 4-5 描线(--border) / 6-7 hover·focus 线(--border-strong，建议新增) / 9-10 accent / 11-12 文字(--muted/--text)。现状 15 token/套结构兼容，新增不改名。
- **对比执法**：正文 Lc≥60 口径（暗色主场景）；accent 在正文链接位若不达标，降级=链接用 --text+下划线、accent 只留大字/粗体/非正文载体（token 不变用法降档）。
- **间距**：4px 基刻度 6 枚（4/8/12/16/20/24，Open Props 同构纯拷值零依赖），现状值就近收编。
- **字号**：6 枚收编现值——hero clamp(1.9rem,4.5vw,2.75rem) 升格 --fs-h1 1.75 / --fs-title 1.05 / --fs-body 0.95 / --fs-meta 0.82 / --fs-micro 0.75（rem）。
- **display 衬线（若未来采概念脸）**：≥1.6rem 才许衬线（SimSun 小字号细弱，Windows 实况）；系统栈先试（Noto Serif SC→Songti→SimSun），不合适降回黑体+字重对比；中文 webfont 数 MB，首版不背。
