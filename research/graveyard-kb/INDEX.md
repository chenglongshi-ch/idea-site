## 评审时怎么用（N+1 流水线，P1 定稿）

1. 拉**当期** graveyard.json（api.github.com contents API 通道；killedbyai.net 直连超时）——库不存原料，每轮用最新数据。
2. 每透镜 = 本库笔记 + 当期语料对应切片进上下文 → 独立出一列论断（严重度 + 引用具体条目 + deathType 语境标注）。透镜互不见面，不辩论不投票。
3. 主持人（+1）只归纳不表决；分歧保留呈现。
4. **作者人裁终审**；报告模板必带下方「统一诚实边界」。
5. 评审后学习环回写：本轮学到什么写进对应透镜笔记（或显式声明 skip 及原因——沉默即违规）；条目带 confidence+数据截至+run 溯源；数据刷新后回测旧结论（agent 重看新数据对照）。

## 跨透镜观察（主线程合成，本索引独有）

- **凶手榜**：OpenAI 29 / Google 26 / Anthropic 10 / Microsoft 10 = **75/128（59%）**——全库算术（platform-dependency P5）。依赖任何一家=把命交给头号刽子手，且它们连亲儿子都杀（Assistants API 硬切无宽限、Bedrock 403）。
- **跨透镜互证的规律**（独立透镜各自提炼后撞车，confidence 视同上调一档）：
  - **免费层/补贴退潮**：feature-removed P3（一家砍、48 小时羊群跟砍）↔ model-upgrade P8（目录修剪先砍免费层）——「建在别人免费额度上」是双透镜点名的最脆地基。
  - **薄壳被碾平/吸收**：startup-failed P1（ChatPDF 品类级覆灭、Jasper 独角兽塌壳）↔ platform-dependency P4 ↔ feature-removed P2（能力活、身份死、数据不保）——全语料最大死簇，wrapper 型想法的默认死法。
  - **监管斩**：feature-removed P4（平台选最省事的全量关停、无导出）↔ startup-failed P4（审批比产品活得久）——强监管品类双重死法：卖之前被拖死、卖之后一夜蒸发。
  - **用户资产陪葬**：feature-removed P2 ↔ platform-dependency P6 ↔ product-killed 检查单第 7 问——多透镜点名「死的时候用户带不走东西」，既是受害者惨状也是想法的口碑负债。
- **引用去重**：startup-failed 与 platform-dependency 对 ChatPDF/Jasper/Tune/Huxe/Reforged 有意双引（各自视角合法）——跨透镜汇总计数时按机制去重勿双计（startup-failed 边界节已注）。

## solo 转译总原则（五份边界节的合成）

语料 ~70%+ 是大厂/机构行为，对 solo 想法**没有一条规律可以照搬直判**，每条警告必须先转译：

| 透镜 | 对 solo 的真实射程 |
|---|---|
| 产品砍杀 | 组合拳逻辑（P1）基本不适用；FOMO 砍杀/弃杀（P5/P6）转译为「你依赖的面被砍」的间接风险 |
| 功能移除 | 射程=依附面（建在谁的地基上）；完全无平台依赖、有自有用户和离线形态的想法基本不在射程 |
| 创业失败 | 对 solo 最相关但样本全是 VC 制公司；solo 的「冷启动失败/无人问津/弃坑」在语料里**系统性缺席**——判「会不会没人要」别用这个库 |
| 模型升级 | 死者全是模型/端点本体而非产品；用法是拿供应商杀旧能力的机制当武器库，反查想法地基（能力差/速度差/价格差/专能端点/行为一致性/免费层六面） |
| 平台依赖 | 收购类（P1/P2）对 solo 基本不适用（没有收购价值）；薄壳被碾平（P4）对 solo **只会更快**（无合同议价、无迁移缓冲） |

## 统一诚实边界（评审报告模板必带）

1. 首版定位 = **撞车提醒 + 死因视角**，不是判生死。
2. 大厂死法逻辑 ≠ solo 想法死法——每条论断必须带 deathType 语境标注。
3. 样本三重偏差：大厂偏重（70%+）/ VC 制公司偏重 / 死亡可见性偏差（solo 默默死不进坟场——**依赖死法的频率被低估、烈度被高估**）。
4. 128 条 = 结构化死因全网唯一源，不是全宇宙死法：长尾源未并入（>300 条触发检索升级）；开源自托管模型上的产品死法不覆盖；中文死因数据真空。
5. 数据周级更新：引用即快照（条目名+deathType+关键句随报告走，源数据事后改版不失可读）；库内存在复活/改判案例（Adobe Animate 反弹缓刑、Claude Fable 政府令 19 天后重启）——**警告≠死刑**。
